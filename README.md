# Game Predictor

## What
Predict pre game NFL game outcomes using statistical modeling and machine learning. 

## Why
We evaluate whether clustering algorithms, supervised learning, and other ML models improves accuracy vs. baseline. 

Use SHAP values to understand which features are the most important, e.g. QB EPA/Play, home-field advantage, team record, etc. 

Does the model improve as their is more data (later weeks in the season)

## Data
- Source: nflfastR
- Period: 2023 season
